# 《声路·澳门 2D》重构修改计划

依据 `docs/q-align/read.md`（Q1–Q3 已确认方向）与 5 张参考图制定。
目标：把"整图背景 + 发光导航线"重构为"瓦片化真实地图层 + 物理盲道砖 + 盲杖触觉判断"。

## 已确认的决策（来自 read.md）

- 城市结构：關閘现代开阔 → 白鸽巢至大三巴逐渐进入葡中旧城（参考图 4/5 的街区密度 + 2/3 的材质丰富度；图 1 仅作章节地图）。
- 画面：全程可见的暖灰城市（非纯黑白、不压黑），这是对无障碍信息的"游戏化转译"，不模拟角色视野。
- 显色：杖头触碰处恢复完整暖色约 2 秒 → 褪为约 35% 淡彩并永久保留；到达大三巴时整条走过的路线恢复完整色彩。
- 核心突出：盲杖触觉判断。
- 操作：`Space` 精确敲击前方一格；按住 `Shift` + `A/D` 手动摆杖，`W/S` 缓慢挪步；`E` 互动；`H` 重复触觉结果与任务；`Q` = 方向指引箭头（不显示路线）。
- 走错处理：短支路可探索，玩家发现环境不符后自行返回，无自动重置。
- 保留：主角、林伯、17 路、记忆与三种结局；在现有仓库原地重构，先做本地版确认。

## 阶段划分

### 里程碑 1：验证场景「白鸽巢下车 → 盲道转向 → 寻找扶手」

目标：一张可玩地图验证新视觉与新玩法，不重画整个游戏。

1. **盲道瓦片层**（核心工作量）
   - 新增 `src/game/tactile-tiles.ts`：把 `content.ts` 的路径节点栅格化为砖块序列（16px 砖，直行砖四凸纹、转向/站台/路口用 4×4 点阵砖，砖携带语义：straight / turn / platform / crossing / seat）。
   - `scenes.ts` 移除 `drawPath()` 的发光线绘制，改为：盲道砖作为 Tilemap/精灵层**始终渲染**，带 1px 上亮边、1–2px 下阴影、与石板路面的接缝。
   - 杖头接触时仅对 2–4 块邻近砖做增强（凸纹提亮、小颗粒、色彩波纹），不再"召唤路线"。
   - 玩家与杖头精灵的深度排序高于盲道层，形成脚部/杖头遮挡。
2. **暖灰基底 + 色彩记忆**（调整而非重写）
   - 场景底色从深靛蓝提亮到暖灰（调 `updateColorMasks` 的遮罩与场景 tint）。
   - 保留现有 pulse（2 秒全彩）+ persistent（淡彩）双遮罩机制，淡彩饱和度调到约 35%。
3. **触觉判断交互**
   - 杖头触到点阵砖时进入短暂判断态，HUD 给出方向性文案（"左侧有新盲道"等），由砖的语义+路径拓扑计算。
4. **短支路**
   - 保留现有封闭支路，补充"环境不符"的触觉线索（盲道中断、材质突变），让玩家自行折返。
5. **Q 方向箭头**：保留现状，确认不显示路线（已实现）。
6. **本地验证**：`npm test` + 浏览器实测整段流程，截图对比参考图。

### 里程碑 2：公交段重做（關閘候车 → 车厢）

- 出发前路线简报（文字+语音，`H` 可重复）。
- 辨别 17 路站牌、等待车门开、上车、杖头确认座位边缘后 `E` 坐下。
- 關閘场景改现代开阔风格（玻璃/混凝土/金属栏杆）。

### 里程碑 3：旧城段与路口、大三巴

- 白鸽巢→大三巴的密度渐变（石板路、葡式立面、骑楼、窄巷）。
- 斜向路口接入新盲道瓦片层。
- 中断应对策略补全：手机确认位置、询问路人（平等策略，不影响结局评价）。
- 到达大三巴时走过的路线整体恢复完整色彩（终章演出）。

### 里程碑 4：打磨与交付

- 生活化 NPC（参考图 2/3）、章节间澳门像素城市背景；2026-08-05 起不再显示路线圆点或连线，只保留场景起止文字卡。
- `npm run build` + `npm run test:sites`，确认 `dist/client/index.html`、`dist/server/index.js`、`dist/.openai/hosting.json` 后再谈公开部署。（2026-08-05 已跑通：build:sites 构建成功，test:sites 4/4 通过，三件产物齐全；环境无 npm，用 `node node_modules/...` 等价命令执行。）

## 素材策略（已确认 2026-08-04）

- 采用方案 b：真正的 tilemap + 独立图块素材，不再以整张 AI 背景图作为场景本体。
- 盲道砖：16px 砖，凸纹/点阵按 32px 观感绘制。
- 路线记忆图砍掉；手机确认位置与询问路人放到里程碑 3；公交段细节放到里程碑 2。
- 所有新素材保持原创澳门像素美术，不复制参考游戏素材；继续记录到 `ASSET_SOURCES.md`。

## 风险

- 瓦片化意味着放弃"整图 AI 背景"的快速出图方式，素材一致性与工作量是最大风险——故里程碑 1 只做一张图验证。
- 暖灰提亮后需重新做 Design QA（现有 `design-qa.md` 结论基于暗色版）。
