# 声路·澳门 2D

一款以白杖触觉、环境声音和城市记忆为核心的桌面 Web 像素游戏。玩家从拱北口岸搭乘 17 路巴士，在白鸽巢下车并穿过旧城，前往大三巴与林伯赴约。

城市默认以明亮暖灰呈现。白杖触碰会让附近街景短暂恢复完整暖色，并在体验模式中留下淡彩记忆；黑夜模式下，未被点亮的城市会重新归黑。

## 本地运行

需要 Node.js 20 或更高版本。

```bash
npm ci
npm run dev
```

项目面向桌面 Chrome / Edge 和键盘操作。

## 操作

- `WASD` / 方向键：行走
- `Space`：向当前方向敲击一根盲杖，读取前方与脚下材质
- `E`：交谈、确认物体、乘车、坐下或执行当前互动
- `Q`：显示目标方向并朗读当前任务
- `G`：短暂照亮整个场景，冷却 8 秒
- `H`：重复最近触觉和当前任务
- `F`：进入或退出全屏
- `Esc`：退出全屏、暂停或关闭当前可关闭弹窗

## 游戏模式

- **体验模式**：白杖点亮约 2 秒，随后留下淡彩记忆。
- **黑夜模式**：未点亮区域保持全黑，不保存淡彩记忆；Q 的方向与语音提示和体验模式一致。

## 当前旅程

正常流程包括：

1. 在拱北口岸回应工作人员并了解正确扶盲方式。
2. 沿触觉盲道辨认 17 路站牌并上车。
3. 在没有连续盲道的车厢内寻找刷卡机、座位和下车按铃。
4. 乘车前往白鸽巢，聆听报站与雨声记忆。
5. 请求安全过街，探索旧城商铺、短巷与行人线索。
6. 沿坡道到达大三巴，与林伯和女儿会合。

## 测试与构建

```bash
npm test
npm run build
npm run build:offline
npm run build:sites
npm run test:sites
```

- 标准构建：`dist/`
- 可双击打开的离线单文件：`offline-dist/index.html`
- Sites 构建会生成 `dist/client/`、`dist/server/` 和 `dist/.openai/hosting.json`
