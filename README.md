# 声路·澳门 2D

独立的桌面 Web 像素游戏切片。玩家以一名45岁的中性旅人为主角，在雨后黄昏从關閘搭乘17路巴士，经白鸽巢步行前往大三巴与林伯赴约。

## 本地运行

```bash
npm run dev
```

开发地址默认为 Vite 输出的本地地址。首版只支持桌面 Chrome / Edge 与键盘。

## 操作

- `WASD`：行走
- `Space`：盲杖敲击，显示前方路线
- `Shift`：90度横扫
- `Q`：8格范围路线提示
- `E`：上车、坐下、收集记忆、回应角色
- `H`：重复当前任务并朗读
- `Esc`：暂停与辅助菜单

## 构建

```bash
npm test
npm run build
npm run build:offline
```

- 标准构建：`dist/`
- 可双击离线单文件：`offline-dist/index.html`

依赖通过目录联接保存在 `D:\work\LinkSee-cache\web-game-2d-deps\node_modules`，源码与存档仍在项目目录。

## 当前切片

包含真实上车、沿车厢盲道找座、`E` 坐下、17路过场、白鸽巢下车、旧城盲道、主动握持扶手、安全请求通过斜向路口、大三巴与三种结局。开发环境提供流程跳转栏，生产构建与离线包中不会出现。

当前版本未经视障人士实测，不代表真实失明体验，也不构成无障碍认证。
